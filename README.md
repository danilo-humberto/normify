# 🚀 Normify

O **Normify** é uma aplicação web SaaS moderna que formata automaticamente documentos `.doc` e `.docx` de acordo com as normas mais recentes da ABNT.

O projeto foi desenvolvido com foco em **simplicidade**, **rapidez** e **excelente experiência do usuário**.

## ✨ Funcionalidades

- 📄 Upload de arquivos `.doc` ou `.docx`
- ⚡ Formatação automática nas normas ABNT
- 🌙 Modo escuro / ☀️ Modo claro
- 🌍 Suporte a múltiplos idiomas (PT, EN, ES)
- 🎯 Interface limpa e intuitiva
- 📱 Design totalmente responsivo

## 🧠 Como Funciona

1. Envie seu documento
2. O sistema processa e formata automaticamente
3. Baixe o arquivo já padronizado

## 🛠️ Tecnologias Utilizadas

- **React**
- **TailwindCSS**
- **shadcn/ui**
- **Vite ou Next.js**
